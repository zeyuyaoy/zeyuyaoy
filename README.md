### Development

Use curly braces for every `if`, `else`, and loop body, including single statements.
Prettier handles indentation, spacing, and line wrapping with a 100-character target
(long strings and URLs may remain longer).

- `bun run lint:fix` adds missing braces and applies ESLint fixes.
- `bun run format` formats source, styles, tests, scripts, and configuration.
- `bun run check` checks formatting, lint, types, tests, and the production build.

Generated files, lockfiles, and public assets are excluded from formatting.
